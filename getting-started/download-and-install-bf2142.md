# ① Download & Install BF2142

In this tutorial, we’ll guide you through various online resources for downloading the game and show you the proper steps for installation. If you have any questions or run into any issues, don’t hesitate to join our [Discord server](https://discord.com/invite/VnxTDPBebZ) — we’re always happy to help!

<details>

<summary>Can my PC handle the game ?</summary>

Most modern laptops or desktops are up to the task.&#x20;

* If your PC can handle _Windows 7_ or newer, and runs _Office 2013_ or later without any issues, it should be able to run this game just fine too.

- If your PC can’t run this game smoothly, you might want to think about _upgrading to a better one_ 😄

Here are the minimum requirements::

* OS: Windows XP, Administrator Access
* CPU: 1.7 GHz Intel Pentium 4 / AMD Athlon XP
* RAM: 512 MB
* Disk Space: 2.2 GB
* Display Card: NVIDIA GeForce FX 5700 / ATI Radeon 9500 \[?[^1]]
* Resolution: 800 x 600 16 bits colour

</details>

<details>

<summary>Are there any Mac versions of the game ?</summary>

Yes, there is technically a Mac version of the game, but we don’t offer any downloads for it here. If you’re eager to play BF2142 on a Mac, your best options are to run it in a Windows virtual machine or use Boot Camp to run Windows on your Mac.

If you’re set on finding a native Mac version, we wish you the best of luck with your search — you’ll probably need to do some digging on Google!

</details>

### Procedures

{% stepper %}
{% step %}
Download `BF2142_Setup.rar` from [Downloads](download-and-install-bf2142.md#downloads) → <mark style="color:blue;">Standard Edition v1.01</mark>.
{% endstep %}

{% step %}
Create a new folder on your desktop.
{% endstep %}

{% step %}
Open `BF2142_Setup.rar` with your [file archiver](#user-content-fn-2)[^2].
{% endstep %}

{% step %}
Drag and drop everything from the `.rar` file into your new folder.
{% endstep %}

{% step %}
Find `setup.exe` in that folder and double-click it to start the installer. **\[**[**?**](#user-content-fn-3)[^3]**]**
{% endstep %}

{% step %}
When prompted by [<mark style="color:blue;">User Account Contro</mark>](#user-content-fn-4)[^4]<mark style="color:blue;">l</mark>, click <mark style="color:blue;">Yes</mark> to allow the installer to make changes on your device.
{% endstep %}

{% step %}
Follow the setup wizard to complete the installation — there are a few [important notes](download-and-install-bf2142.md#remarks) along the way, so keep an eye out for those. **\[**[**TL;DR**](#user-content-fn-5)[^5]**]**

* If you see a popup saying <mark style="color:blue;">This game has only been tested on WinXP(32bit)</mark>, just click <mark style="color:blue;">Confirm</mark>. **\[**[**?**](#user-content-fn-6)[^6]**]**
*   When prompted for a serial code, simply use one of these [<mark style="color:blue;">Standard Edition</mark>](#user-content-fn-7)[^7] keys to continue. [**\[?\]**](#user-content-fn-8)[^8]

    ```
    SDV5-JZDE-L6B8-P2Q4-1911
    SVMV-LBNV-W7W5-J3X4-1911
    E6HH-DWUG-U8X1-R8F0-1911
    UTFP-4DMN-D2U0-X3T3-1911​
    TRCL-YBIJ-D4H4-Y3O5-1911
    ```
* It’s recommended to install the game to the [default path](#user-content-fn-9)[^9], but you can choose a different location if you prefer.
* For the best experience, install the <mark style="color:blue;">English version</mark> to take advantage of the <mark style="color:blue;">HD English fonts</mark> included with the [Remaster mod](../project-remaster/download-and-install-remaster-mod.md).
* Feel free to skip BattleCammo setup by clicking <mark style="color:blue;">Cancel</mark>. **\[**[**?**](#user-content-fn-10)[^10]**]**
* Select <mark style="color:blue;">No, install GameSpy Comrade later</mark> to skip GameSpy Comrade setup. **\[**[**?**](#user-content-fn-11)[^11]**]**
* When asked to register an EA account, just click <mark style="color:blue;">REGISTER LATER</mark> to move on. **\[**[**?**](#user-content-fn-12)[^12]**]**
* None of the multiplayer servers use PunkBuster anti-cheat, so you can safely skip installing it.
{% endstep %}

{% step %}
Once the installation finishes, close the wizard but _don’t launch the game just yet_. **\[**[**?**](#user-content-fn-13)[^13]**]**
{% endstep %}

{% step %}
Next, make sure to [patch the game to v1.51](download-and-install-v1_51-patch.md) — _don’t skip this step_! **\[**[**?**](#user-content-fn-14)[^14]**]**
{% endstep %}
{% endstepper %}

{% tab title="Retail DVD" %}
**Battlefield 2142 Retail DVD**

The only way to obtain the game “legitimately” these days is by buying a _second-hand_ retail DVD. Keep in mind, though, that used copies often come with product keys that are already activated or expired. While this might seem to defeat the purpose of spending money, nostalgia is a great reason to support a classic like this.

If you really love the game and have a bit of extra cash, we encourage you to pick up a physical copy. You might be surprised — many dedicated fans still own their original discs, some dating back to 2005! As we always say, we’re true Battlefield lovers, and that’s exactly why we created this website.

Amazon, eBay, and local used video game stores are usually the best places to look for second-hand games like this.

* Be sure the listing specifically mentions that the manual is included, since the serial code needed for installation is printed on the back cover of the manual.
* If possible, check before buying that the disc edition matches the manual edition — mixing them up can prevent you from installing the game.
* And don’t forget — you’ll need a DVD-ROM drive to run the disc.
